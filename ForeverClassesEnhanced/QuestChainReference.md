# FCE Quest Chain Reference

**Total unique quests in CharacterData:** 272
**Quests with chain data:** 133
**Quests needing chain review:** 139

## How to use this list

Each quest below appears in CharacterData.lua but has NO entry in QuestChains.
For each quest, decide:
- **Standalone** (no prerequisite chain) - no action needed
- **Has prerequisites** - add chain to QuestChainData.lua

Format for QuestChainData.lua:
```lua
[END_QUEST_ID] = {
    {questID1, "First Quest Name"},
    {questID2, "Second Quest Name"},
    ...
    {END_QUEST_ID, "End Quest Name"},
},
```
